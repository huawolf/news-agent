### 1. huggingface/speech-to-speech ⭐ 今日 +442

**语言/许可：** Python / Apache-2.0  
**总 Stars：** 10.3k  
**仓库：** [GitHub](https://github.com/huggingface/speech-to-speech)

**项目定位：** 为自托管语音 Agent 提供低延迟模块化管线（VAD → STT → LLM → TTS），并通过 OpenAI Realtime 兼容的 WebSocket API 对外暴露。

- **目标用户：** 需要构建语音助手、实时对话机器人、语音交互硬件的开发者与机器人团队。
- **核心能力：** 全组件可替换——STT 支持 Parakeet、Whisper、Faster-Whisper、Paraformer 等；LLM 层兼容任意 OpenAI 协议端点，可对接 vLLM、llama.cpp 完全本地化部署；TTS 支持 Qwen3-TTS、Kokoro、ChatTTS 等；提供 Realtime/WebRTC、本地麦克风、裸 PCM WebSocket、TCP Socket 四种运行模式。
- **与现有方案差异：** 相比 OpenAI Realtime API，是完整可本地部署的开源替代；已在生产环境（Reachy Mini 机器人对话后端）验证，多后端抽象与活跃维护使其更适合作为语音 Agent 的基础设施层。

### 2. bytedance/deer-flow ⭐ 今日 +209

**语言/许可：** Python / MIT  
**总 Stars：** 78.9k  
**仓库：** [GitHub](https://github.com/bytedance/deer-flow)

**项目定位：** 面向数分钟到数小时长周期任务的通用 SuperAgent 编排框架，通过子代理、记忆、沙箱、工具与技能系统处理深度研究、编码与内容生成。

- **目标用户：** 需要构建深度研究、自主编码、多工具长链路 Agent 的工程师与 AI Infra 团队。
- **核心能力：** 2.0 为从上到下的重写：支持技能/工具扩展、Claude Code 集成、会话目标管理、上下文压缩、长期记忆、沙箱文件系统、MCP 服务、IM 渠道接入及 LangSmith/Langfuse 追踪；内置终端工作台与定时任务；兼容 vLLM、OpenRouter、Responses API 等多模型后端。
- **与现有方案差异：** 相比 v1 的 Deep Research 框架，2.0 扩展为通用 agent harness，工程化完整度高（安装向导、诊断、支持包机制），在多 Provider 与子代理管控层面比多数开源 Agent 框架更接近生产形态。

### 3. github/copilot-sdk ⭐ 今日 +142

**语言/许可：** 多语言（TypeScript/Python/Go/.NET/Rust/Java）/ MIT  
**总 Stars：** 10.3k  
**仓库：** [GitHub](https://github.com/github/copilot-sdk)

**项目定位：** 将 GitHub Copilot Agent 的生产级 agent 运行时嵌入自有应用的官方 SDK，通过 JSON-RPC 复用 Copilot CLI 的规划、工具调用与文件编辑能力。

- **目标用户：** 希望在应用、SaaS 产品或 IDE 插件中集成 Agent 能力的开发者与平台团队。
- **核心能力：** 覆盖六种主流语言的 SDK；支持自定义 agent、skills 与 tools；权限处理器可审批、拒绝或定制工具调用；认证支持 GitHub 登录、OAuth App 与 BYOK（自带 OpenAI / Microsoft Foundry / Anthropic 密钥）。
- **与现有方案差异：** 开发者无需自建 agent 编排层，直接调用 Copilot CLI 背后的生产验证运行时；统一 JSON-RPC 架构使上层应用可替换 LLM 后端，属于平台级 Agent 基础设施信号。
